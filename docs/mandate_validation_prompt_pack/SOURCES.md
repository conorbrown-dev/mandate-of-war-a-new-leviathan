# Tooling Sources

These sources were checked when this prompt pack was created.

- GdUnit4 command-line tool:
  https://godot-gdunit-labs.github.io/gdUnit4/latest/advanced_testing/cmd/

- GdUnit4 SceneRunner accessors:
  https://godot-gdunit-labs.github.io/gdUnit4/latest/advanced_testing/scene_runner/accessors/

- GdUnit4 simulated actions:
  https://godot-gdunit-labs.github.io/gdUnit4/latest/advanced_testing/scene_runner/actions/

- Godot command-line options, including `--headless`, `--write-movie`, `--fixed-fps`, and `--quit-after`:
  https://docs.godotengine.org/en/latest/tutorials/editor/command_line_tutorial.html

- Godot viewport capture:
  https://docs.godotengine.org/en/latest/tutorials/rendering/viewports.html

Agents should verify APIs against the project's installed Godot/GdUnit4 versions rather than assuming the latest documentation exactly matches the repository.
