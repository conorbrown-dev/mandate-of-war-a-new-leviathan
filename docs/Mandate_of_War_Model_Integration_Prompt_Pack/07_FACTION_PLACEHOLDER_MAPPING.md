# Goal 7 — Temporary Faction Prototype Mapping

Create a temporary roster mapping actual processed donor models to fictional Mandate of War roles.

This is prototype art, not final lore identity.

## Faction Direction
### Elite / Precision
Prefer clean modern silhouettes, strong sensor language, lower visual clutter.

### Mass Warfare
Prefer rugged conventional silhouettes, mechanically obvious construction, simple/cheap forms.

### Industrial / Experimental
Prefer modular modern donors, unusual silhouettes, infrastructure/support-heavy visuals.

## Deliverable Table
For every mapped prototype record:
- faction
- gameplay role
- prototype unit ID
- visual ID
- donor asset ID/path
- reason for temporary mapping
- replacement priority
- future-art direction

Only use assets actually present in the inventory.

## Historical Donors
T-34, Spitfire, etc. are design-DNA donors. If temporarily shown in gameplay, mark them explicitly as prototype placeholders.

## Example Future Art Notes
### T-34-descended Mass Warfare MBT
Preserve low silhouette, sloped armor, compact turret, rugged simplicity. Replace with fictional unmanned/reduced-profile turret, active protection, modern sensors, modular armor, near-future drivetrain, and faction markings.

### Fighter donor
Preserve role/aerodynamic family. Change intake details, tail/wing geometry, sensor apertures, weapons, materials, and faction-specific design language.

Do not derive fictional stats from historical performance or model dimensions.
