# Power grid model sources

The power station, steel pylon and wooden power pole are original models made
for Mandate of War. `tools/generate_power_models.py` builds them from
measurements written in the script, with no third-party geometry, textures or
other content, so there is no licence to honour and nobody outside the project
to credit. The game still lists them in the F2 **Audio & Credits** panel, as the
project's own work, so every model on screen is accounted for.

The files are in `godot/project/assets/source_3d/power/`. `power_models.json`
beside them records each model's height, the spacing between supports and where
its conductors attach; the game reads it to hang the wires. Rerun the script to
rebuild all four files; the output is the same every time.

Issue #4 asked for sourced royalty-free models, or Blender-generated ones if
none could be sourced. Blender is not installed on the Mac this was built on
and nothing was downloaded, so the models are generated by a plain Python
script that writes glTF directly. They can be replaced by sourced or
Blender-made models without code changes, as long as `power_models.json` gives
the new attach points. Any sourced replacement must be royalty free for
commercial use and credited in the F2 panel.

Conductors are drawn by the game as line geometry between the attach points,
and the sparks of a cut line are a particle effect built in
`godot/project/power_grid_view.gd`; neither uses an asset file.
